# LDAP 비활성 계정 (⑥) — 설계

> 브랜치 `ldap-disabled-account` (origin/main `22f5d08` 에서 분기).
> 발단: 정리 묶음(⑤) 설계 중 발견 — [`2026-09-25-cleanup-bundle-design.md`](2026-09-25-cleanup-bundle-design.md) §1.

## 1. 문제 — AD 가 막은 계정이 권한을 유지한다

두 LDAP 전략(`GroupOfNamesStrategy`, `DitStrategy`)은 직원을 **`active = true` 로만** 만든다.

`TupleMapper` 는 `active == false` 인 직원의 `direct_member` 튜플을 만들지 않는다. SCIM 은 이 경로로 퇴사자
권한을 지운다(IdP 가 `active: false` 를 보낸다). LDAP 에는 그 경로가 없다.

그래서 AD 에서 계정을 **막기만 하고 그룹에서 빼지 않으면**(흔한 운영 방식이다) 그 직원은 권한을 그대로 유지한다.
AD 가 계정을 막는 표준 방법은 둘이다 — **비활성화**(`userAccountControl` 의 비트)와 **만료일**(`accountExpires`).
리뷰 문서(2026-09-11) §5 는 이것을 "LDAP 쪽 `active` 가 늘 참이라 퇴사자 권한 생존은 SCIM 으로만 검증된다" 는
**테스트 공백(Minor)** 으로 적었지만, 따라가 보면 **동작 결함**이다.

## 2. 결정 — 사용자와 정한 것 (2026-09-25)

**막힌 계정은 SCIM 과 같은 의미의 비활성으로 읽는다.** `active = false` — 멤버십은 남고 튜플만 사라진다(SCIM 이
이미 쓰는 비활성의 정의이고, `ChartExpectation` 도 같은 규칙으로 기대값을 만든다). 관리자 조회에는 "소속은 있지만
비활성" 으로 보이고, 다시 풀면 다음 동기화에서 권한이 돌아온다.

**비활성화와 만료일을 둘 다 읽는다.** 처음 설계는 비활성화 비트만 읽고 만료일은 별건으로 두었다. 둘 다 "AD 가 이
계정을 막았는가" 에 대한 표준 신호라 하나만 읽으면 "만료일로 막은 퇴사자는 권한이 남는" 함정이 그대로 남으므로,
사용자가 ⑥ 에 함께 넣기로 했다.

**속성이 없으면 막히지 않은 것으로 본다.** 설정 스위치를 두지 않는다.

| 접근 | 판단 |
|---|---|
| **비활성 직원으로 읽는다(`active=false`) — 채택** | SCIM 과 의미가 같다. 이미 있는 `TupleMapper`·관리자 조회·재활성화 경로를 그대로 쓴다 |
| 검색에서 뺀다(없는 직원 = 퇴사) | 멤버십까지 사라져 SCIM 과 의미가 갈린다. 비트 매칭 필터(`1.2.840.113556.1.4.803`)가 AD 전용이라 임베디드 서버로 검증할 수 없다 |

| 속성이 없을 때 | 판단 |
|---|---|
| **막히지 않은 것으로 본다 — 채택** | 설정이 필요 없다. AD 는 읽고, OpenLDAP·테스트 서버는 지금처럼 전원 활성이다 |
| 설정 스위치를 두고, 켜면 속성이 필수 | "AD 인데 속성을 못 읽는" 경우를 잡는다. 대신 AD 배포에서 스위치를 잊으면 지금 결함이 그대로 남는다 |

## 3. 읽기 규칙 — 표준 신호 둘

AD 표준(MS-ADTS)이 계정을 막았다고 알리는 신호는 둘이다. **둘 중 하나라도 막혔다고 하면 비활성이다.**

### 비활성화 — `userAccountControl`

| 값 | 결과 |
|---|---|
| 없음 | 막히지 않음 |
| 정수, `ACCOUNTDISABLE` 비트(`0x2`)가 켜짐 | **막힘** |
| 정수, 그 비트가 꺼짐 | 막히지 않음 |
| 정수가 아님 | **그 회차를 실패시킨다** — 표준 밖이다 |

**비트로 검사한다.** AD 는 여러 플래그를 더한 값을 준다(`512` 보통 계정, `514` = 512 + 비활성, `66050` = 비활성 +
암호 만료 없음). `== 514` 처럼 값을 비교하면 틀린다.

### 만료일 — `accountExpires`

값은 1601-01-01 UTC 부터 100나노초 단위로 센 정수다.

| 값 | 결과 |
|---|---|
| 없음 | 막히지 않음 |
| `0` 또는 `9223372036854775807` | 막히지 않음 — AD 표준이 이 둘을 "만료 없음" 으로 쓴다 |
| 지금 이전(같은 시각 포함) | **막힘** |
| 지금 이후 | 막히지 않음 |
| 정수가 아님 | **그 회차를 실패시킨다** |

**"지금" 은 동기화가 도는 시각이다.** 만료는 디렉터리가 바뀌지 않아도 시간이 지나면 생긴다. 전략은 앱의 `Clock` 빈을
받아 그 시각과 비교한다 — 테스트는 고정 시계로 한다. LDAP 동기화는 매일 전체를 다시 계산하므로, 만료일이 지나면 다음
동기화에서 자연히 비활성으로 잡힌다.

### 규칙의 자리

두 규칙은 `connector-ldap` 의 `strategy` 패키지에 **도우미 하나**로 두고 두 전략이 같이 쓴다. 두 전략이 같은
디렉터리를 같은 스냅샷으로 읽는다는 것이 이 커넥터의 약속이라(`TwoStrategiesSameShapeTest`) 규칙이 한 곳에 있어야
한다. 속성 이름은 AD 표준이라 설정으로 빼지 않는다.

## 4. 적용

- **groupOfNames:** 사용자 매퍼가 읽은 값을 `RawEntry` 에 싣고 `DirectoryUser` 를 만들 때 쓴다.
- **DIT:** `DirectoryUser` 를 만드는 자리에서 바로 쓴다.
- **시계:** 두 전략이 `Clock` 을 받는다. `LdapConfig` 가 앱의 `Clock` 빈을 넘긴다(`app-ldap` 에 이미 있다).
- **검색은 바꾸지 않는다.** 속성 목록을 지정하지 않는 검색이라 두 속성(일반 속성)은 이미 온다.

**이미 되어 있어 손대지 않는 것:** `TupleMapper` 의 비활성 건너뛰기, 관리자 조회의 `active` 표시, 재활성화 시 차이
계산. **대량 비활성화**는 권한을 많이 지우는 일이라 기존 삭제 가드(30%)가 그대로 막는다.

## 5. 검증

- **단위 — 규칙 (도우미, 서버 없이):** 비활성화 `512` · `514` · `66050` · 없음 · 숫자 아님. 만료일 과거 · 미래 ·
  정확히 지금 · `0` · 최댓값 · 없음 · 숫자 아님. 둘 중 하나만 막혀도 비활성. 고정 시계로 한다.
- **단위 — 두 전략 (`connector-ldap`, 스키마 검사를 끈 임베디드 서버):** 비활성화된 직원과 만료된 직원이 `active=false`
  로 읽히고 **그룹 멤버로는 남는지**. 숫자가 아닌 값이면 읽기가 실패하는지. RED 부터.
- **E2E (`LdapSyncEndToEndTest`, 기본 `test` 에 드는 빠른 테스트):** 비활성화 → 그 직원의 튜플이 없다, 상태에는
  멤버십이 남고 `active=false` → 다시 활성화 → 튜플이 돌아온다. 만료일이 과거인 직원도 튜플이 없다. `TupleMapper`
  까지 실제로 이어지는지 보는 자리다.
- **머지 전:** `./gradlew cleanTest test` 와 `./gradlew cleanScaleTest scaleTest`.

## 6. 이 설계가 말할 수 없는 것

- **실제 AD 로는 검증하지 못한다.** 인증 슬라이드 이후다.
- **막힌 직후부터 다음 동기화까지는 권한이 남는다.** LDAP 은 주기 동기화라 비활성화든 만료든 다음 회차에 반영된다.
  이 설계 이전부터 모든 LDAP 변경이 그렇다.
- **잠금(lockout)은 다루지 않는다.** 암호 오입력 같은 일시적 상태라 권한과 무관하게 둔다.
- **AD 에서 동기화 계정이 두 속성을 읽지 못하게 막혀 있으면 전원이 막히지 않은 것으로 읽힌다**(§2 에서 받아들인
  것). AD 기본 권한은 인증된 계정에게 읽기를 허용하므로 비표준 설정에서만 생긴다.
- **규모 테스트에는 넣지 않는다.** 규모 테스트는 스키마 검사를 켜 두는데 `inetOrgPerson` 에는 두 속성이 없어
  스키마를 확장해야 한다. 동작은 E2E 가 증명한다. 그래서 `SyncVerifier` 의 비활성 분기는 LDAP 규모 시나리오에서
  여전히 타지 않는다.
